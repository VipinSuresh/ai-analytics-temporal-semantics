# Limitations

- Small synthetic dataset.
- One business domain.
- One pinned model.
- Three runs per question/configuration.
- Experiment 2 was added after Experiment 1 and is exploratory.
- Experiment 1 used explicitly temporal wording.
- Config B vs Config C execution differences are descriptive, not causal.
- Several SQL errors involved the same metric/column naming mismatch and should not be attributed to architecture.
- The experiment does not establish that analytics agents generally prefer historical semantics.
- The experiment does not answer whether disclosure is sufficient when multiple business interpretations are valid.
